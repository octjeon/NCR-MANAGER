본 시스템은 주식회사 대한정공의 조선 및 배관 품질검사 현장에서 발생하는
부적합 사항을 실시간으로 등록하고, 조치 진행 상황을 관리하며, 사내 표준 양식인
[부적합보고서(DH-QP-870-01)]를 자동으로 생성 및 PDF 출력하고,
관리자 모드를 통한 자료 수정·삭제 및 매월 품질 실적 분석 통계를 제공하는 통합 품질경영 시스템입니다.

2. 화면 구성 및 기본 메뉴
===============================================================================
상단 헤더(Header)의 탭 버튼을 클릭하여 원하는 화면으로 전환할 수 있습니다.

[ 상단 메뉴 구성 ]
 1) [ 📝 신규 등록 ]
    - 현장에서 발견된 부적합 사항을 단계별(1~4단계)로 등록하는 화면
 2) [ 📊 진행 관리 ]
    - 등록된 부적합 목록 조회, 진행중/완료 상태 확인 및 후속 조치 처리 화면
 3) [ ⚙️ 관리 ] (관리자 전용)
    - 관리자 암호 인증 후 사용자 관리, 등록 자료 수정/삭제, 매월/기간별 실적 분석 수행
 4) [ 📖 매뉴얼 ]
    - 화면 상단 우측 버튼 클릭 시 상세 매뉴얼 모달 즉시 열람

3. [기능 1] 사용자 로그인 및 계정 관리
===============================================================================

[ 3-1. 초기 화면 로그인 및 로그인 상태 유지 ]
 1. 사용자(등록자) 선택:
    - 드롭다운 목록에서 본인 성명을 선택하거나 하단 빠른 선택 뱃지 클릭
 2. 비밀번호 입력:
    - 본인의 계정 비밀번호 입력 (초기 접속자는 기본 비밀번호: 122333)
 3. [한 번 로그인 후 계속 사용하기 (로그인 상태 유지)] 체크:
    - 체크 상태로 로그인 시, 앱을 닫았다가 다시 열어도 재로그인 없이 자동 유지
 4. [로그인] 버튼 클릭하여 메인 화면 진입

[ 3-2. 초기 기본 비밀번호 및 개인 비밀번호 변경 ]
 - 모든 사용자의 초기 기본 비밀번호: **122333**
 - 개인 비밀번호 변경 방법:
   ① 화면 상단 헤더 우측 본인 성명 옆 [🔑 비번 변경] 버튼 클릭
   ② 현재 비밀번호(초기값: 122333) 입력 후 새 비밀번호(4자리 이상) 2회 입력
   ③ [비밀번호 변경 저장] 버튼 클릭 시 즉시 변경 완료

[ 3-3. 관리자의 사용자(등록자) 계정 관리 ]
 관리자는 [관리] 탭 ➔ [사용자(등록자) 관리] 서브탭에서 등록자를 통합 관리합니다.
 - 신규 사용자 추가: 성명 입력 후 [+ 신규 사용자 등록] 클릭 (초기비번 122333 자동 세팅)
 - 비밀번호 초기화: 비밀번호 분실 시 [초기화] 클릭 시 즉시 122333으로 리셋
 - 비밀번호 임의 지정: [비번 변경] 클릭 후 관리자가 원하는 새 암호 지정 가능
 - 사용자 삭제: 불필요한 계정 [삭제] 버튼으로 정리

4. [기능 2] 신규 부적합 등록 방법 (단계별 안내)
===============================================================================

[ 1단계: 검사 기본 정보 입력 ]
 1. 호선번호(Ship No.) 입력:
    - 4자리 숫자(예: 2401)를 입력합니다. (숫자만 자동 입력됨)
 2. 검사장소(Inspection Location) 선택:
    - [본사], [1공장], [2공장], [온산공장], [대원], [신라] 중에서 드롭다운 선택.
    - 목록에 없는 새 공장/협력사가 필요한 경우 하단 [+ 검사장소 추가] 버튼으로 즉시 등록.
 3. 검사일자: 당일 날짜가 기본 설정되며 필요 시 달력에서 일자 변경 가능.
 4. 등록자: 현재 로그인된 사용자 이름으로 자동 지정됨.
 5. [ 다음 단계 (검사항목 선택) ➔ ] 버튼 클릭.

[ 2단계: 검사품목 / 검사항목 선택 (콤보 박스 단일 선택) ]
 1. 검사품목 / 검사항목 콤보 박스 선택 (1개 필수 선택):
    - 콤보 박스 드롭다운 목록을 클릭하여 대상 품목 1개를 선택합니다.
    - CS PIPE SPOOL VISUAL, CS PIPE SPOOL HYD, SUS PIPE SPOOL VISUAL,
      SUS PIPE SPOOL HYD, PAINT, LIFTING LUG 등 목록에서 선택 시 하단에 확인 카드가 표시됩니다.
    - 목록에 없는 항목은 우측 상단 [+ 검사항목 추가] 버튼을 눌러 즉시 마스터 등록 및 자동 선택.
 2. [ 다음 단계 ➔ ] 버튼 클릭.

[ 3단계: 부적합 유형 선택 및 세부내용 작성 ]
 1. 부적합 유형 선택 (복수 선택 가능):
    - WELDING, PAINT, ASSEMBLE, MIS ALIGN, VISUAL, LEAK, MATERIAL, DESIGN 중 선택.
 2. 부적합 세부내용 구체적 기재:
    - 결함 발생 위치(스풀 번호, 블록 번호), 불량 상태, 규격 미달 치수 등 상세 기재.
 3. [ 다음 단계 (증거사진 첨부) ➔ ] 버튼 클릭.

[ 4단계: 증거사진 첨부 (최소 1장 필수, 최대 4장) ]
 1. [ 📷 카메라 직접 촬영 ]: 스마트폰 카메라로 현장 결함 부위 즉시 촬영 첨부.
 2. [ 🖼️ 갤러리에서 선택 ]: 스마트폰 앨범에서 1장 또는 여러 장을 동시에 선택하여 첨부.
 3. 개별 슬롯 터치: 원하는 슬롯을 터치하여 촬영 또는 갤러리 선택.
 4. 사진 삭제: 등록된 사진 우측 상단의 붉은색 휴지통 아이콘 클릭 시 즉시 삭제.
 5. 사진 자동 최적화: 첨부 즉시 해상도 800px 및 품질 0.72로 고화질 자동 압축 처리됨.
 6. [ 💾 부적합 등록 완료 ] 클릭 시 클라우드 영구 저장 및 발행번호(DHQ-xxxx) 발급.

5. [기능 3] 부적합 진행 관리 및 조치 완료 처리
===============================================================================

[ 5-1. 목록 조회 및 실시간 필터링 ]
 - 상단 KPI 요약: 전체 건수, 진행중 건수, 완료 건수 자동 집계.
 - 상태별(진행중/완료), 검사장소별, 부적합유형별 다중 필터링 및 실시간 키워드 검색.

[ 5-2. 상세 내역 조회 및 사진 확대 (라이트박스) ]
 - 카드의 [상세보기] 클릭 시 전체 내역 팝업 표시.
 - 사진 클릭 시 전체화면 라이트박스 열림 (100%~300% 확대/축소, 이전/다음 탐색 가능).

[ 5-3. 담당자 지정 및 원클릭 이메일 통보 ]
 - 진행 담당자 성명 및 이메일 입력 후 [ ✉️ 담당자 메일 통보 ] 클릭 시
   기본 메일 프로그램과 연동되어 부적합 내역이 정돈된 본문으로 즉시 발송 준비.

[ 5-4. 상태 관리 및 조치완료 등록 ]
 현장 결함 조치가 완료되었을 때 처리하는 절차:
 1. 해당 카드 우측 하단 [ 상태관리 / 조치 ] 버튼 클릭.
 2. 원인 분석 및 특이사항 입력.
 3. 조치 방안 선택: [반품], [재작업], [특채], [용도변경], [폐기] 중 1개 선택.
 4. 조치완료 증거사진 첨부 (최소 1장 필수, 최대 4장 / 카메라 또는 갤러리).
 5. 조치확인자(검사원) 성명 입력 후 [ 💾 조치완료 저장 ] 클릭.
 6. 상태가 '완료'로 변경되며 완료일자가 오늘 날짜로 기록됨.

6. [기능 4] 표준 부적합보고서(DH-QP-870-01) 발행 및 A4 PDF 인쇄
===============================================================================
주식회사 대한정공의 공식 사내 표준 양식인 [부적합보고서 (DH-QP-870-01)]를 자동 생성합니다.
 1. 발행 방법: [진행 관리] 또는 [관리] 탭에서 각 건의 [ 🖨️ 보고서 ] 버튼 클릭.
 2. 보고서 구성:
    - 사내 CI 로고, 문서번호(DH-QP-870-01), 개정: 0, 부적합보고서 헤더
    - 3단 결재란 (작성 / 검토 / 승인)
    - 기본 정보 (호선, 장소, 일자, 검사원, 검사항목, 부적합유형)
    - 본문 (부적합 세부 결함 내용)
    - 사진란 1 (발생 당시 부적합 증거사진 1~4장)
    - 사진란 2 (조치 완료 후 확인사진 1~4장)
    - 후속 조치란 (원인분석, 특이사항, 조치방안 체크, 확인일자 및 확인자)
 3. 출력 기능:
    - [ 📥 고화질 PDF 다운로드 ]: A4 1페이지 규격 최적화 PDF 즉시 저장
    - [ 🖨️ 바로 인쇄 ]: 프린터로 종이 보고서 즉시 출력

7. [기능 5] 관리 탭 (관리자 인증, 자료 수정/삭제, 매월·기간별 실적분석)
===============================================================================

[ 7-1. 관리자 암호 인증 ]
 - 관리 탭 클릭 시 관리자 인증 팝업 표시.
 - 기본 비밀번호: **admin1234** (또는 daehan1234)
 - 우측 상단 [암호 변경] 버튼을 통해 언제든지 관리자 비밀번호 변경 가능.

[ 7-2. 등록 자료 수정 (사진 추가/삭제 및 자동 최적화 기능 포함) ]
 - 목록의 [ ✏️ 수정 ] 버튼 클릭 시 수정 모달(EditRecordModal) 열림.
 - 모든 텍스트 및 기본 정보 수정 가능.
 - **사진 관리 기능**:
   ① 부적합 증거사진(1~4장) 및 조치완료 사진(1~4장) 각각에 대해 개별 삭제(휴지통 아이콘) 지원.
   ② [카메라 직접 촬영] 또는 [갤러리에서 선택]으로 신규 사진 추가 가능.
   ③ 추가되는 모든 사진은 최대 800px 해상도 및 고품질 압축으로 **실시간 자동 최적화** 처리됨.
   ④ 사진 썸네일의 돋보기 아이콘을 눌러 라이트박스에서 원본 화질 확대 검토 가능.

[ 7-3. 부적합 자료 안전 영구 삭제 ]
 - [ 🗑️ 삭제 ] 버튼 클릭 시 확인 팝업을 거쳐 클라우드 및 기기에서 완전 삭제.

[ 7-4. 호선별·월별 품질 실적 분석 및 그래프 ]
 - [매월 실적], [직접 기간 지정], [전체 누적] 중 선택하여 실적 분석.

8. [기술 안내] 사진 고화질 자동 최적화 및 무제한 저장
===============================================================================
 - 현장 스마트폰 카메라의 대용량 사진(장당 3~10MB)은 시스템에 등록되는 순간
   HTML5 Canvas 리샘플링을 통해 최대 800px 해상도로 자동 축소 및 압축(JPEG 0.72)됩니다.
 - 평균 95% 이상의 용량이 절감(70~100KB)되어 Firestore 1MB 문서 한도와
   브라우저 저장 한계를 완벽히 보호하며, 모바일 로딩 속도를 극대화합니다.
 - IndexedDB 무제한 로컬 저장소를 연동하여 수천 건 이상의 데이터가 누락 없이 영구 보존됩니다.

    바탕화면에 전용 아이콘이 생성되어 원터치 앱으로 편리하게 구동됩니다.

10. 자주 묻는 질문 (FAQ) 및 문제 해결
===============================================================================
 Q1. 초기 로그인 비밀번호는 무엇인가요?
  A. 모든 사용자의 초기 기본 비밀번호는 **122333** 입니다. 로그인 후 상단 [비번 변경]에서 변경하세요.

 Q2. 비밀번호를 분실했을 때는 어떻게 하나요?
  A. 관리자에게 요청하시면 [관리] 탭 ➔ [사용자 관리]에서 즉시 122333으로 초기화해 드립니다.

 Q3. 관리자 마스터 암호를 잊었을 때는?
  A. 비상 마스터 암호인 `admin1234` 또는 `daehan1234`로 접속할 수 있습니다.

 Q4. 검사항목이나 검사장소가 목록에 없을 때는?
  A. 등록 과정에서 [+ 검사장소 추가] 또는 [+ 검사항목 추가]를 눌러 그 자리에서 즉시 등록 가능합니다.

 Q5. 오프라인 상태에서도 데이터가 보존되나요?
  A. 네, 기기 내부 IndexedDB에 보존되며 인터넷 재연결 시 클라우드로 안전하게 자동 동기화됩니다.
