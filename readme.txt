          주식회사 대한정공 부적합 관리 시스템 사용자 설명서 (Manual)

본 시스템은 주식회사 대한정공의 조선 및 배관 품질검사 현장에서 발생하는
부적합 사항을 실시간으로 등록하고, 조치 진행 상황을 관리하며, 사내 표준 양식인
[부적합보고서(DH-QP-870-01)]를 자동으로 생성 및 PDF 출력하고,
관리자 모드를 통한 자료 수정·삭제 및 매월 품질 실적 분석 통계를 제공하는 통합 품질경영 시스템입니다.

1. 시스템 개요 및 접속 방법
===============================================================================
- 지원 기기: PC(데스크톱, 노트북), 스마트폰(Android, iOS), 태블릿
- 권장 브라우저: Google Chrome, Safari, Samsung Internet, Whale
- 접속 URL: 회사 공지 웹 링크를 통해 접속
- 클라우드 연동: 등록된 모든 데이터와 사진은 Firebase Firestore 클라우드 서버에
  실시간으로 자동 동기화되어 사무실과 현장 간 실시간 공유됩니다.

2. 화면 구성 및 기본 메뉴 (3대 탭)
===============================================================================
상단 헤더(Header)의 탭 버튼을 클릭하여 원하는 화면으로 전환할 수 있습니다.

[ 탭 메뉴 구성 ]
 1) [ 📝 신규 등록 ]
    - 현장에서 발견된 부적합 사항을 단계별(1~4단계)로 등록하는 화면
 2) [ 📊 진행 관리 ]
    - 등록된 부적합 목록 조회, 진행중/완료 상태 확인 및 후속 조치 처리 화면
 3) [ ⚙️ 관리 ] (관리자 전용)
    - 관리자 암호 인증 후 등록 자료의 수정, 삭제 및 매월/기간별 실적 분석을 수행하는 화면

3. [기능 1] 신규 부적합 등록 방법 (단계별 안내)
===============================================================================

[ 1단계: 기본 정보 입력 ]
 1. 호선번호(Ship No.) 입력:
    - 4자리 숫자(예: 2401)를 입력합니다. (숫자만 자동 입력됨)
 2. 검사장소(Inspection Location) 선택 (신규 기능):
    - [본사], [1공장], [2공장], [온산공장], [대원], [신라] 중에서 콤보박스(드롭다운)로 선택합니다.
    - 새로운 검사장소나 협력사 공장이 필요한 경우, 드롭다운 하단의 [ + 검사장소 추가 ]
      버튼을 눌러 언제든지 새 장소를 등록할 수 있습니다. 등록된 장소는 즉시 전사 마스터로 공유됩니다.
 3. 검사일자 선택:
    - 기본값은 오늘 날짜로 자동 지정되며, 필요 시 달력에서 날짜를 변경합니다.
 4. 등록자 선택:
    - 본인 성명을 드롭다운에서 선택합니다.
    - 본인 이름이 목록에 없을 경우, [ + 신규 등록자 추가 ] 버튼을 눌러 성명을 입력하면
      즉시 마스터 목록에 추가되어 향후 계속 사용할 수 있습니다.
 5. [ 다음 단계 (검사항목 선택) ➔ ] 버튼 클릭

[ 2단계: 검사항목 및 부적합유형 선택 ]
 1. 검사항목 선택 (복수 선택 가능):
    - CS PIPE SPOOL VISUAL, CS PIPE SPOOL HYD, SUS PIPE SPOOL VISUAL,
      SUS PIPE SPOOL HYD, PAINT 등 해당하는 항목을 터치/클릭합니다.
    - 필요한 항목이 없을 경우 [ + 신규 검사항목 추가 ]로 추가 가능합니다.
 2. 부적합유형 선택 (복수 선택 가능):
    - WELDING(용접), PAINT(도장), HYD TEST(수압), VISUAL(외관),
      MIS ALIGN(단차), BENDING(곡가공), CRACK(균열) 등 결함 유형을 선택합니다.
    - [ + 신규 부적합유형 추가 ]로 새로운 유형을 추가할 수 있습니다.
 3. [ 다음 단계 (상세내용 작성) ➔ ] 버튼 클릭

[ 3단계: 부적합 상세내용 작성 ]
 1. 발생 위치 및 결함 현상을 구체적으로 작성합니다.
    (예: 2401호선 본사 E/R 하부 Spool No.12 버트 용접부 언더컷 및 단차 2.5mm 발생)
 2. [ 다음 단계 (증거사진 첨부) ➔ ] 버튼 클릭

[ 4단계: 증거사진 첨부 (최소 1장 필수, 최대 4장) ]
 사진 추가 방법은 두 가지 중 편리한 방법을 선택할 수 있습니다.

 ① [ 📷 카메라 직접 촬영 ] 버튼 사용:
    - 스마트폰 카메라가 즉시 실행되어 현장 사진을 바로 촬영하여 등록합니다.
 ② [ 🖼️ 갤러리에서 선택 ] 버튼 사용:
    - 기기에 이미 저장된 앨범/갤러리에서 1장 또는 여러 장을 선택하여 한 번에 등록합니다.
 ③ 개별 슬롯 터치:
    - 슬롯 1 ~ 4번 중 원하는 슬롯을 터치하면 [카메라 직접 촬영] 또는 [갤러리 선택] 팝업이
      나타나 원하는 방식으로 사진을 등록하거나 변경할 수 있습니다.
 ④ 사진 삭제:
    - 등록된 사진 우측 상단의 붉은색 휴지통 아이콘을 누르면 해당 사진만 삭제됩니다.

[ 최종 등록 완료 ]
 - 모든 입력 완료 후 [ 💾 부적합 등록 완료 ] 버튼을 누르면 클라우드에 영구 저장됩니다.
 - 등록 완료 후 [ 전체 등록 목록 확인 ] 팝업이 열려 방금 등록된 건을 바로 확인할 수 있습니다.

4. [기능 2] 부적합 진행 관리 및 조치 완료 처리
===============================================================================

[ 4-1. 목록 조회 및 실시간 필터링 ]
 - 상단 요약 카드: 전체 건수, 진행중 건수, 완료 건수가 자동 집계됩니다.
 - 진행상태 뱃지 및 검사장소(본사, 공장 등)가 각 카드에 명확히 표기됩니다.

[ 4-2. 상세 내역 조회 및 사진 확대 ]
 - 목록에서 카드의 [상세보기] 또는 카드 본문을 클릭하면 상세 팝업이 열립니다.
 - 등록된 사진을 클릭하면 [라이트박스]가 열려 원본 해상도로 확대해서 볼 수 있으며,
   좌우 화살표로 이전/다음 사진을 넘겨볼 수 있습니다.

[ 4-3. 담당자 지정 및 이메일 통보 ]
 - 상세 화면에서 조치 담당자 성명과 이메일 주소를 입력한 후 [ 메일 통보 ] 버튼을 누르면,
   해당 부적합 내용이 미리 작성된 기본 이메일 프로그램이 열려 담당자에게 즉시 발송할 수 있습니다.

[ 4-4. 상태 관리 및 조치완료 등록 ]
 부적합 건에 대한 현장 조치가 완료되었을 때 처리하는 절차입니다.
 1. 목록 카드 우측 하단의 [ 상태관리 / 조치 ] 버튼을 클릭합니다.
 2. 원인파악 입력: 결함이 발생한 근본 원인을 기재합니다.
 3. 특이사항 입력: 조치 시 참고사항이나 특이사항을 기재합니다.
 4. 조치방안 선택:
    - [반품], [재작업], [특채], [용도변경], [폐기] 중 해당하는 방안 1개를 선택합니다.
 5. 조치완료 증거사진 등록 (최소 1장 필수, 최대 4장):
    - [카메라 직접 촬영] 또는 [갤러리에서 선택]을 통해 조치가 완료된 현장 사진을 첨부합니다.
 6. 확인자 성명 입력: 검사 및 조치 상태를 최종 확인한 사람의 성명을 입력합니다.
 7. [ 💾 조치완료 저장 ] 버튼 클릭:
    - 진행상태가 '완료'로 변경되며, 완료일자가 오늘 날짜로 기록됩니다.

5. [기능 3] 표준 부적합보고서(DH-QP-870-01) 발행 및 인쇄
===============================================================================

본 시스템은 주식회사 대한정공의 공식 품질경영 표준 양식인
[부적합보고서 (양식번호: DH-QP-870-01, 개정번호: 0)]를 자동 생성합니다.

 1. 발행 방법:
    - [진행 관리] 또는 [관리] 탭에서 각 건의 [ 🖨️ 보고서 ] 버튼을 클릭합니다.
 2. 보고서 양식 구성:
    - 상단: 대한정공 CI 로고, 문서번호(DH-QP-870-01), 개정: 0, 부적합보고서 타이틀
    - 결재란: 작성 / 검토 / 승인 3단 결재란
    - 기본정보란: 발생일자, 발행번호, 검사자, 호선번호, 검사장소, 부적합유형, 검사항목
    - 본문: 부적합 상세내용 기재란
    - 사진란 1: 부적합 증거사진 (1번 ~ 4번 균등 격자 배치)
    - 사진란 2: 조치완료 증거사진 (1번 ~ 4번 균등 격자 배치)
    - 원인파악란: 결함 원인 분석 내용 (넓은 행 높이 반영)
    - 특이사항란: 조치 특이사항 내용 (넓은 행 높이 반영)
    - 조치방안란: 반품, 재작업, 특채, 용도변경, 폐기 체크박스 표시
    - 확인란: 조치확인일자, 조치확인자 서명명
 3. PDF 다운로드 및 인쇄:
    - [ 📥 고화질 PDF 다운로드 ]: A4 용지 1페이지 규격에 최적화된 PDF 파일로 즉시 저장됩니다.
    - [ 🖨️ 바로 인쇄 ]: 프린터로 바로 인쇄하거나 브라우저 인쇄 창을 통해 출력합니다.


===============================================================================
6. [기능 4] 관리 탭 (관리자 인증, 자료 수정/삭제, 매월·기간별 실적분석)
===============================================================================

[ 6-1. 관리자 암호 인증 ]
 - 관리 탭을 클릭하면 보안을 위해 [관리자 전용 인증] 화면이 표시됩니다.
 - 기본 비밀번호: **admin1234** (또는 daehan1234, 1234 지원)
 - 암호 확인 후 관리자 권한이 활성화되며, 우측 상단의 [암호 변경] 버튼을 통해
   관리자가 원하는 새로운 비밀번호로 변경할 수 있습니다.
 - 작업 완료 후 [잠금] 버튼을 누르면 즉시 보안 잠금 상태로 전환됩니다.

[ 6-2. 등록 자료 수정 및 삭제 ]
 - 검색 및 필터: 호선, 발행번호, 검사장소, 등록자, 부적합 세부내용 검색 및
   조치상태(진행중/완료), 검사장소, 부적합유형 필터를 제공합니다.
 - [ ✏️ 수정 ]:
   호선번호(4자리), 검사장소, 검사일자, 등록자, 검사항목, 부적합유형, 상세내용,
   조치상태(진행중/완료), 담당자 정보, 완료일자, 원인분석, 재발방지대책을 모두
   직접 수정하고 저장할 수 있습니다.
 - [ 🗑️ 삭제 ]:
   잘못 등록되었거나 불필요한 건을 영구 삭제할 수 있으며, 오삭제 방지를 위해
   상세 확인 팝업을 거쳐 Firestore 클라우드와 기기에서 완전히 삭제됩니다.

[ 6-3. 지정 기간 및 매월 실적 분석 ]
 - 기간 선택:
   ① [매월 실적]: 년도(2024, 2025, 2026...) 및 월(1월 ~ 12월)을 선택하여
      해당 월의 부적합 실적을 바로 조회합니다.
   ② [직접 지정]: 시작일자와 종료일자를 직접 설정하여 원하는 기간을 분석합니다.
   ③ [전체 누적]: 전체 누적 데이터를 바탕으로 분석합니다.
 - 핵심 KPI 요약 카드:
   - 총 부적합 발행 건수
   - 조치 완료 건수 및 완료율(%)
   - 진행 중 건수
   - 최빈 발생 부적합 유형 및 점유율
 - **분석 1: 부적합유형별 분석**:
   - 용접불량, 가공불량, 치수불량 등 유형별 발생 건수와 백분율 점유율(%),
     조치완료 건수와 진행중 건수, 완료율 그래프 및 상세 순위표를 제공합니다.
 - **분석 2: 검사품목 / 검사항목별 실적 분석**:
   - LIFTING LUG, PIPE SPOOL, HULL BLOCK 등 검사항목별 불량 발생 실적,
     점유율 순위, 막대 그래프 및 통계표를 제공합니다.
 - **보조 분석**:
   - 검사장소별(본사, 1공장, 2공장, 온산공장, 대원, 신라 등) 발생 분포 및 호선별 발생 현황을 한눈에 파악할 수 있습니다.

 - [ 📊 엑셀 / CSV 내보내기 ]: 선택한 기간의 부적합 실적 데이터를 엑셀 호환 CSV 파일로 즉시 다운로드합니다.
 - [ 🖨️ 분석표 인쇄 및 PDF 저장 ]:
   - [분석표 인쇄] 버튼 클릭 시 공식 사내 양식(DH-QA-ST-01) 기반의 **[호선별 부적합 품질 실적 분석표] 미리보기 모달**이 열립니다.
   - **프린터 인쇄**: 상단 [인쇄] 버튼을 눌러 공식 결재란, KPI 요약, 유형별·품목별·장소별 통계표가 포함된 A4 규격 문서를 인쇄합니다.
   - **A4 PDF 다운로드**: 상단 [PDF 다운로드] 버튼을 누르면 고화질의 A4 PDF 파일([품질실적분석표]_기간.pdf)이 자동 생성되어 기기에 즉시 저장됩니다.
   - **배율 조절**: 돋보기(확대/축소) 버튼으로 모바일이나 작은 화면에서도 분석표를 편안하게 검토할 수 있습니다.

8. 데이터 동기화 및 자주 묻는 질문(FAQ)
===============================================================================

 Q1. 등록한 데이터는 어디에 저장되나요?
  A. 구글 클라우드 기반의 Firebase Firestore 데이터베이스에 실시간 저장됩니다.
     스마트폰에서 등록한 내역이 사무실 PC 화면에도 즉시 실시간으로 반영됩니다.

 Q2. 인터넷 연결이 일시적으로 끊기면 데이터가 사라지나요?
  A. 아닙니다. 기기 내부(LocalStorage)에 안전하게 보관되며, 인터넷이 다시
     연결되면 클라우드 서버와 안전하게 동기화됩니다.

 Q3. 관리자 암호를 잊어버렸을 때는 어떻게 하나요?
  A. 기본 마스터 비밀번호로 `admin1234` 또는 `daehan1234`를 입력하면 언제든지
     관리자 모드로 접속하여 새로운 비밀번호로 재설정할 수 있습니다.

 Q4. 검사장소(공장/협력사)를 새로 추가하려면 어떻게 하나요?
  A. [신규 등록] 1단계 화면의 검사장소 선택창 우측 하단 [ + 검사장소 추가 ]를
     누르거나, [관리] 탭의 자료 수정 창에서 즉시 추가할 수 있습니다.
